# A2 E2 #336 — preregistered native effect decision separation (source-only)

Owner [#336](https://github.com/kinoko34077/UniverseGenome/issues/336); source baseline `131739a7e8d004c9f9153e80aa4bccb49ce242c6` with [PR342](https://github.com/kinoko34077/UniverseGenome/pull/342) merged. No effectful seeds/physical modification. This is an independent pure Python scorer of a **future genuine, already authorized outcome-exposed** E2 JSON, not a generated research result.

The existing paired-contact collector returns actual matched native source/recipient context and postlatents if the eventual runner executes. A matched recipient delta can be directly observed, but the current compressed runner DOES NOT establish whether the teacher-specific changed word survives +1000 generations through genuine new carriers. An outcome category named "TRANSIENT" cannot mean merely "persistence has not been proven". Such conflation would turn missing lineage evidence into a false observation.

Proposed deterministic two-axis pre-outcome handling:

- Control validity first: old 6-checkpoint masked_copy goldens, positive544 same-teacher B/B, negative545 B/H full equality and explicit snapshot, observed/unobserved branch state, separate source-distinct original no-teacher reference, original role/seed/operator/horizon/resource condition, exact matched event count consistency.
- No matched contacts, only confounded contacts, missing original control or budget overflow → `NOT_EVALUABLE_NO_POSTHOC_SEED_REPLACEMENT`, no zero denominator fabricated.
- Valid matched precontext + no actual recipient difference → `NEGATIVE_NO_MATCHED_RECIPIENT_EFFECT` **for this exposed-contact sample only**.
- Valid matched postlatent delta → `LOCAL_RECEIVER_EFFECT_RETENTION_UNRESOLVED`, direct observation only. Not automatically `TRANSIENT_PHYSICAL_EFFECT_NOT_L3` or `OUTCOME_EXPOSED_RETENTION_CANDIDATE_NOT_INDEPENDENT_L3` without actual generation/cell-life lineage evidence; no independent L3 claim.

This addition does **not** rewrite the previously frozen E2 protocol, modify the effectful runner, enable the activation marker, or change the forbidden cohorts, score threshold, intervention, original h0 or production defaults. Before activation, reconcile the exact classification labels with the original protocol and make this pure scorer part of the accepted runtime validation, with fresh review of all source lock entries after merge. Until then, F5 is **partially implemented but not accepted as the final scientific decision gate**.

Tests are explicitly synthetic dictionaries only. Dual-runtime source CI never runs an R2 seed, an h0 or original/alternate physics. The actual research remains HOLD.
