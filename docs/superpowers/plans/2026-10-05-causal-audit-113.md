# Learning-Channel Causal Audit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Execute Issue #113's fixed L0-L7 matched-snapshot causal audit after the terminal #111 density arena.

**Architecture:** Add a research-only harness under `research/` that clones one authoritative `UniverseState` snapshot into Control, A-only, A→B→NULL, and A→C→NULL branches. It records field-level deltas and hashes at fixed checkpoints, then evaluates output reachability and canonical success without changing production physics or defaults.

**Tech Stack:** Python 3.11, existing `core.physics`, `core.experiment`, JSONL/JSON evidence, `unittest`.

**Spec:** GitHub Issue #113, “Learning-channel causal audit after density arena”.

## Global Constraints

- Use density 32 as the diagnostic condition and density 4 as the low-density control.
- Use deterministic seeds 0..31 and clone every branch from the same pre-stimulus snapshot.
- Keep teacher symbols B and C distinct; keep A and terminal NULL fixed.
- Check pre-stimulus, teacher-byte, teacher-sequence-complete, +10, +100, and +1000 generations.
- Track HP, latent, bond, structure, position, lifecycle, active-cell count, full snapshot digest, output path, and event sequence.
- Treat first failed L0-L7 level as terminal for this audit; do not modify physical laws or rewrite canonical retention/noise semantics.
- Require deterministic replay equality and record generation/sec plus instrumentation overhead.

## Review Focus

- Branches must share the exact same source snapshot before stimulus; test hash and generation equality.
- B and C must be compared as teacher-attributable branches, not as unrelated random runs; test the same seed/density and fixed checkpoint names.
- Snapshot comparison must ignore only non-state bookkeeping and must expose field-level differences; test identical and changed arrays.
- A no-input/control branch must not be counted as a canonical success; test the result classification separately from arbitrary wrong output events.
- Resumed output must be reproducible; test the deterministic replay record before the full matrix.
