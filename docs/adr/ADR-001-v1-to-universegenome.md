# ADR-001 — SCA v1 semantic architecture to local-physics UniverseGenome
Status: accepted

## Decision
Do not carry explicit Syntax, meaning_tags, semantic clustering, MemoryZone semantics or tag-based thought-loop behavior into the UniverseGenome core.

## Reason
UniverseGenome tests whether persistent structure and useful response can emerge from local physical time evolution.

## Consequence
Selected optimizer/save/visualization ideas may be adapted outside the inner universe; v1 semantic behavior is not preserved merely for code reuse.
